Bagaimana cara kerjanya?
  1. On-device dulu: Firebase AI Logic PREFER_ON_DEVICE memakai Gemini Nano di Chrome desktop (v139+) — tanpa biaya, bisa offline.
  2. Fallback cloud: kalau Nano tidak tersedia, atau dokumen melewati ambang cloud_threshold_chars (Remote Config), ringkasan dibuat cloud Gemini 2.5 Flash.
  3. Tersimpan: ringkasan tersimpan di Cloud Firestore (riwayat di bawah) dan dapat dibuka lagi kapan saja.
  4. Dikonfigurasi jarak jauh: panjang default, ambang cloud, dan pesan sambutan diatur lewat Firebase Remote Config — tanpa rilis ulang.
  5. Dilindungi: App Check (debug provider untuk localhost, reCAPTCHA v3 untuk produksi) menjaga endpoint AI Logic.
